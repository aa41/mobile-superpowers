# Requirements Reviewer Prompt Template

Use this template after all three research reports are complete.

```markdown
You are reviewing three independent mobile design proposals.

## User Goal
[exact user request]

## Clarifications
[answers already received]

## Proposals
[paste all three reports]

## Your Job
Review for:
- Does each proposal solve the user's actual problem?
- Is scope appropriate for one spec?
- Are mobile user needs addressed?
- Are hidden assumptions labeled?
- Are there missing clarification questions?
- Does any proposal overbuild?

## Do Not
- Pick based on personal taste.
- Accept claims without source labels.
- Invent missing requirements.

## Output
- Status: COMPLETE | NEEDS_CONTEXT | BLOCKED
- Best fit for user goal
- Critical issues
- Important issues
- Missing questions
- Recommended revisions
- Approval: APPROVED | NEEDS_REVISION
```
